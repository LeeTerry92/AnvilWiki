Emberfang（アッシュ・ワーデン）は、Anvil Questでほとんどのプレイヤーが最初に遭遇する大型ボスです。このガイドでは、すべての攻撃パターン、安全な攻撃チャンス、そしてこの戦闘を簡単にする装備構成を解説します。

## ボス概要

| ステータス | 値                                    |
| ---------- | ------------------------------------- |
| 推奨レベル | 8以上                                 |
| HP         | 4,200                                 |
| 弱点       | 氷                                    |
| 耐性       | 火                                    |
| 場所       | Ashen Keep、Shattered Isles 第1幕     |

Emberfangはゲートキーパー的なボスです。楽に倒せないなら、まだ中盤に進む準備ができていません。良いニュースは、彼には厳密で学習可能なパターンがあることです。

## フェーズ1：ファイアボルト斉射（HP 100%〜66%）

Emberfangは戦闘開始と同時に、拡散状に3発の火の矢を発射します。矢は中速で飛び、直撃で180ダメージを与えます。

**対策**: 右にストレイフしましょう。3発すべて左から右に扇状に広がるため、右方向への一定移動だけで斉射を完全に回避できます。

<Video id="dQw4w9WgXcQ" title="フェーズ1のファイアボルト回避(デモ埋め込み)" />

## フェーズ2: 燃え盛る大地（HP 66%〜33%）

HPが66%になると、Emberfangは地面を叩き、広がる炎の輪を生成します。ヒットすると2秒間灼熱状態になり、直後のボルト斉射で致命傷になります。

**対策**: 各輪をジャンプで越えましょう。タイミングは余裕があり（輪ごとに0.4秒の猶予）。ダッシュは輪ではなく、追撃の斉射のために温存してください。

## フェーズ3: インフェルノ激化（HP 33%〜0%）

HPが33%を下回ると、Emberfangは激化状態に入ります。移動速度+30%、ボルト斉射が3発から5発に、燃え盛る大地の輪が2倍の頻度で発生します。

**対策**: フェーズ3開始時に氷属性ポーションを使いましょう。氷バフは灼熱効果を完全にキャンセルし、この戦闘で最も危険なメカニクスを無力化します。

## 推奨装備

| スロット   | アイテム               | 理由                                        |
| ---------- | ---------------------- | ------------------------------------------- |
| 武器       | Frostpike（氷）        | 火弱点ボスに2倍ダメージ                     |
| 防具       | Emberweaveセット       | 火耐性+40                                   |
| アイテム   | 上級凍結ポーション     | フェーズ3の灼熱をキャンセル                 |
| アクセサリ | クリティカルチャーム   | ボルト溜め中の頭部は2倍クリティカルゾーン   |

## よくあるミス

- **ボルトに向かって回避する。** 初心者はパニックで前方にダッシュし、3発すべて受けます。フェーズ1ではダッシュせずストレイフしましょう。
- **炎の輪にダッシュを使う。** ダッシュはクールダウン6秒です。追撃のボルトのために必要です。輪はジャンプで越えましょう。
- **凍結ポーションを忘れる。** 氷バフなしのフェーズ3はコイントスです。あれば実質的に戦闘終了です。

## まとめ

フェーズ1は右にストレイフ。フェーズ2は輪をジャンプ。フェーズ3開始時に凍結ポーション。[Frostpikeの評価](/ja/guides/weapon-tier-list/)を持参。これで勝てます。

初めてのボス戦なら[初心者ガイド](/ja/guides/beginner-guide/)にポーションのタイミングまとめがあります。凍結ポーションの費用は[コードページ](/ja/codes/all-codes/)の無料ゴールドで賄えます。
